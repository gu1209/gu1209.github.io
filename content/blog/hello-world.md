## 个人主页的搭建

这个个人主页使用 Next.js 14 构建，部署在 GitHub Pages 上。整个项目采用了以下技术栈：

- **框架**: Next.js 14 (App Router)
- **样式**: Tailwind CSS
- **部署**: GitHub Pages + GitHub Actions
- **博客**: Markdown + gray-matter + marked
