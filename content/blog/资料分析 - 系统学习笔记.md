## 一、基础概念与核心公式

### 1.1 ABRX 四量关系

资料分析的核心框架围绕四个量展开：

|符号|含义|说明|
|---|---|---|
|**A**|基期（前期）|比较的基准值|
|**B**|现期（本期）|当前时期的值|
|**X**|增长量|绝对差值|
|**R**|增长率|相对差异|

> **ABRX 核心公式组**
> 
> - `B = A + X = A(1 + R)`
>     
> - `X = B - A = AR = BR/(1+R)`
>     
> - `R = X/A = (B-A)/A = B/A - 1`
>     
> - `A = B - X = B/(1+R) = X/R`
>     

**六组已知关系：**

1. 已知 A、B → X=B-A, R=X/A
    
2. 已知 A、X → B=A+X, R=X/A
    
3. 已知 B、X → A=B-X, R=X/A（用415或假设分配）
    
4. 已知 B、R → 用**415份数法**或**假设分配**求A、X
    
5. 已知 A、R → X=AR, B=A+AR
    
6. 已知 X、R → A=X/R, B=A+X
    

### 1.2 同比与环比

|类型|含义|示例|
|---|---|---|
|**同比**|与上年同期相比|2023年12月 vs 2022年12月|
|**环比**|与上一相邻统计周期相比|2023年12月 vs 2023年11月|

### 1.3 百分数与百分点

> **[注意]** 百分数（%）通过数值相除得到，用于比重、增长率。百分点通过百分数相减得到，用于两个增长率/比重的差值。 例：比重从48%变为52%，上升了 **4个百分点**（不是4%）。

### 1.4 增速变化的表述

|表述|去年增速计算|
|---|---|
|今年增长率10%，增幅**扩大/上升**5个百分点|10%-5% = **5%**|
|今年增长率10%，增幅**缩小/下降**5个百分点|10%+5% = **15%**|
|今年增长率-10%，增速**扩大**5个百分点|-10%-5% = **-15%**|
|今年增长率-10%，增速**缩小**5个百分点|-10%+5% = **-5%**|
|今年增长率-10%，**降幅扩大**5个百分点|-(10%-5%) = **-5%**|
|今年增长率-10%，**降幅收窄**5个百分点|-(10%+5%) = **-15%**|

> **[易错]** "降幅扩大"和"降幅收窄"的主体是"降幅"（绝对值），方向与普通表述相反！降幅扩大意味着负得更多。

### 1.5 倍数与增长率

> **倍数与增长率互换**
> 
> - 增长了 1.5 倍 = 增长率为 150%
>     
> - A 比 B 增长了 60% → A 是 B 的 1.6 倍
>     
> - 1 倍 = 100%
>     
> - A 是 B 的多少倍：`A/B`
>     
> - A 比 B 多多少倍：`A/B - 1`
>     

> **[审题陷阱]** "是多少倍"和"多多少倍"相差1！城镇消费品零售额约是乡村的6.5倍，则城镇比乡村**多约5.5倍**。

### 1.6 常用分数-百分数对照表

> **必须熟记**
> 
> |百分数|分数|百分数|分数|百分数|分数|
> |---|---|---|---|---|---|
> |50%|1/2|16.7%|1/6|28.6%|2/7|
> |33.3%|1/3|14.3%|1/7|42.9%|3/7|
> |25%|1/4|12.5%|1/8|66.7%|2/3|
> |20%|1/5|11.1%|1/9|9.1%|1/11|

## 二、速算技巧

### 2.1 加法技巧

**尾数法**：多个数字精确求和且选项末尾数字不同时，从尾数入手，一般观察两位。

> **[注意]** 选项是"4.9万""2.1万"形式时不能用尾数法（后面数字可能被约掉）。

**高位叠加法**：从高位加起（与竖式相反），抓住主要矛盾。适用于非精确求和。

### 2.2 减法技巧 - 分段法

将多位数减法分成两段，尽可能不用借位；若无法避免借位，用负数代替。

> **[方法]**
> 
> - 512-481 → 51-48=3, 2-1=1 → 结果 31
>     
> - 721-688 → 基准值法：721-700+700-688=21+12=33
>     
> - 1723-494 → 17-4=13, 23-94=-71 → 1300-71=1229
>     

> **[技巧] 前三位减法判断增量：** 若前三位相减已大于目标值→一定超过；等于→看后两位是否够减；小于→一定不够。

### 2.3 乘法技巧

**小分互换法**：将百分数乘数转化为常见分数。

> `784 × 25% = 784 × 1/4 = 196` `632 × 12.5% = 632 × 1/8 = 79`

**乘法拆分法**：将百分数拆成两个简单数值之和/差。

> 常用拆分：`55%=50%+5%` | `48%=50%-2%` | `97%=100%-3%` | `103%=100%+3%`

**乘法放缩法**：将乘数拆为整百×(1±小百分比)。

> 例：`212×332 = 212×300×(1+10.7%) ≈ 63600+6800 ≈ 70500`

### 2.4 除法技巧

**拆分法（除法核心）**：对直除的优化，借助选项"猜"出答案。

> **[三类拆分]**
> 
> 1. 分子在分母50%附近 → 先拆出50%
>     
> 2. 分数约等于1 → 先拆出100%
>     
> 3. 分子很小 → 拆出10%、5%或1%
>     

示例：`250÷484 = (242+8)/484 = 50%+ → 约52%`

**除法放缩**：分子分母同比例扩大或缩小，分式不变。适用于分母接近整百时。

> 例：`858/981 → (858+17)/(981+19) = 875/1000 = 87.5%`

> **[积累] 除法分类：** 求A/X → 415/假设分配；比重（部分/整体）→ 拆分法；平均数/倍数 → 直除。

### 2.5 415份数法

> **415份数法核心**
> 
> 若 `R = 1/n`，则：
> 
> - 基期 A = n 份，变化量 X = 1 份，现期 B = (n+1) 份
>     
> - `X = B / (n+1)`，`A = B × n / (n+1)`
>     

示例：B=642，R=25%=1/4 → 份数 4、1、5 → X=642/5=128.4

> **[注意]**
> 
> - 增长率为负时变为"4(-1)3"，X为负
>     
> - R近似为分数时，"估大则一份变大，估小则一份变小"
>     
> - 增长率>10%、选项差距>2%时最适用
>     

### 2.6 误差修正法

> **误差修正步骤**
> 
> 1. 将 R 近似为 1/n，用份数法求 X'
>     
> 2. `R差 = R实际 - R使用`
>     
> 3. `X = X' × (1 ± R修)` （R实际>R使用时加，反之减）
>     

**R修系数表：**

|近似分数|适用范围|X'|R修|
|---|---|---|---|
|1/9 (11.1%)|10%~11.8%|B/10|R差×8|
|1/8 (12.5%)|11.8%~13.4%|B/9|R差×7|
|1/7 (14.3%)|13.4%~15.5%|B/8|R差×6|
|1/6 (16.7%)|15.5%~18.5%|B/7|R差×5|
|1/5 (20%)|18.5%~22.5%|B/6|R差×4|
|1/4 (25%)|22.5%~30%|B/5|R差×3|
|1/3 (33.3%)|30%~40%|B/4|R差×2.2|
|1/2 (50%)|40%~60%|B/3|R差×1.3|
|2/3 (66.7%)|60%~80%|B×0.4|R差×0.9|
|1 (100%)|80%~120%|B/2|R差×0.5|

> **[积累]** 20%以内假设分配有优势，20%以上误差修正法有优势，差别不大，可根据习惯选择。

### 2.7 假设分配法

> **假设分配核心**
> 
> - 公式：`X = A × R`
>     
> - 核心思想："抓大放小"，大数分完后小数有误差也不影响
>     
> - 步骤：确定分配数 → 画出分配树 → 逐步分配
>     

**最后一步分配规则：**

|R 大小|方法|
|---|---|
|R ≤ 25%|用被分配数的10%、20%修正|
|R ≈ 33%|X = B/4|
|R ≈ 50%|X = B/3|
|R ≈ 66%|X = 0.4B|
|R > 80%|X = B/2|

**选项极近时的假设思维**：选取选项间中间值X'代入，A'=B-X'，再算X=A'×R验证。

## 三、ABRX 高频考点

### 3.1 基期（A）

**一般基期**：代入法、直除法、假设分配法。

**间隔基期**：

> **间隔基期公式**
> 
> `间隔增长率 R = R1 + R2 + R1×R2` `基期 A = 现期 / (1 + R)`

**基期和差**：分别用假设分配求两个基期，再求和或差。

**已知变化情况求基期**：

> `A = X / R`（已知增量X和增长率R时使用）

### 3.2 现期（B）

- **假设增量求后期**：求X，列不等式 `B = A + nX > 目标值`
    
- **假设增速求后期**：`B = A + AR` 逐年推算
    
- **按实际增长率求后期**：
    

> `按基期价格计算的现期 = 现期 / (1+名义R) × (1+实际R)`

### 3.3 增长量（X）

- **一般增长量**：X = B - A 或用415/假设分配
    
- **两期增长量的比值**：分别求X1、X2再求比
    
- **各部分增量之和 = 总增量**：
    

> `X其他 = X总 - X1 - X2 - ...`

### 3.4 增长率（R）

**一般增长率**：`R = X/A = (B-A)/A`

**间隔增长率**：

> `R = R1 + R2 + R1 × R2`
> 
> R1×R2 在两者都较小时可忽略；一大一小时取"小正数"

**间隔增长率逆运用**：已知间隔R和一年R1，求另一年 `R2 ≈ R - R1`

**比值增长率（平均数增长率）**：

> **比值增长率公式**
> 
> A = B/C，B增长率R1，C增长率R2
> 
> `A的增长率 = (R1 - R2) / (1 + R2)`
> 
> 比值倍数 = 比值增长率 + 100%

题型识别：人均收入、平均分、单位面积产量等。

**乘积增长率**：

> **乘积增长率公式**
> 
> A = B × C，B增长率R1，C增长率R2
> 
> `R = R1 + R2 + R1 × R2`

常见场景：

- 总产量 = 亩产 × 面积
    
- 总销额 = 销量 × 单价
    
- **部分 = 整体 × 占比**（有占比想乘积！）
    

### 3.5 年均增长量

> **年均增量 = (末期 - 基期) / n**

|问法|基期是否前推|计算|
|---|---|---|
|"十三五"时期(2016-2020)|要推（用2015年）|(2020值-2015值)/5|
|2016年到2020年这五年|要推|(2020值-2015值)/5|
|2015-2020年（图表从2015起）|不推|(2020值-2015值)/5|

> **[易错]** "十三五时期"等五年规划说法，基期必须前推一年。图表已有第一年且从该年问起则不推。

### 3.6 年均增长率

> **(1 + r)^n = 末期 / 基期**
> 
> 近似：`末期/基期 ≥ 1 + nr`（r 极小时）

**需记住的幂次值：**

|值|结果|
|---|---|
|1.05^4|1.22|
|1.1^4|1.46|
|1.15^4|1.75|
|1.2^4|2.07|

**假设年均增速相同求后期**：

> `第2n年值 = 末期² / 基期值`

## 四、比重类

### 4.1 现期比重

> **现期比重公式组**
> 
> - `比重 = 部分 / 整体`
>     
> - `部分 = 整体 × 比重`
>     
> - `整体 = 部分 / 比重`
>     
> - `比重和（差）= 部分和（部分差）/ 整体`
>     

> **[方法] 饼状图技巧：** 利用1/2、1/3、1/4、1/8等特殊比例判断。从12点钟方向顺时针依次排列。

### 4.2 基期比重

> **基期比重公式**
> 
> `基期比重 = 现期比重 × (1+整体R) / (1+部分R)`
> 
> 口诀：基期比重 = 现期比重 × "1+增长率反过来"

> **[积累]** 基期平均值、基期倍数、基期比值均可视为"基期比重"，用同一公式。

### 4.3 隔级比重

存在大集合、中集合、小集合的层级关系。

> `隔级比重 = 小集合/中集合 × 中集合/大集合`

### 4.4 比重趋势

> **比重趋势判断**
> 
> - 部分增速R1 > 整体增速R2 → **比重上升**
>     
> - 部分增速R1 < 整体增速R2 → **比重下降**
>     

**比重趋势多一步**：已知本期比重和趋势方向，反推前期比重。

**比重趋势逆运用**：已知比重变化方向 → 推断部分增速与整体增速的大小关系。

### 4.5 比重差

> **比重差公式**
> 
> `比重差 = (前期部分 / 本期整体) × (部分R - 整体R)`
> 
> 记忆：今年整体分之去年部分 × 增长率之差

> **[方法] 比重差秒杀计：** 比重差的绝对值 **小于** 增速差的绝对值！

**比值差**：可套用比重差公式，但**不可以秒杀**（量级不一定小于增速差）。

> **[注意]** 比重差选项单位多为"百分点"；比值增长率单位为"%"；比值差选项带实际含义单位。

## 五、盐水类（混合思维）

### 5.1 盐水思想核心

> **混合规律**
> 
> 混合比值在两部分比值之间，且**靠近分母更大的一部分**

适用场景：

- 整体增长率 = 进口R与出口R的混合
    
- 累计增长率 = 当月R与上月累计R的混合
    
- 全年R = 上半年R与下半年R的混合
    
- 全国人均收入 = 城镇与农村人均的混合
    

### 5.2 十字交叉法

> **十字交叉模型**
> 
> A部分增长率 a          |r - b|  
>           混合增长率 r  
> B部分增长率 b          |a - r|  
> ​  
> A/B = |r-b| / |a-r|

> **[注意]** 十字交叉求得的是**基期之比**。分母是什么，求的就是什么之比。

### 5.3 线段法

画线标点、按比例分段、按量选点、几何计算。**量与距离成反比**。

### 5.4 三类盐水考法

**① 三浓度排序**

> **部分1浓度 > 整体浓度 > 部分2浓度**

典型应用：已知1-5月和1-6月增速，判断6月增速。

**② 已知3R求量之比**：代入十字交叉求得基期量之比。

**③ 已知2R和量之比求第三R**：先定性（在中间不在正中间），再定量计算。

## 六、比较类

### 6.1 常用比较方法

|方法|适用场景|
|---|---|
|**趋势法**|借用比重趋势：分子增速>分母→分数变大|
|**通分法**|分子或分母换算同样大小后比较|
|**"王者荣耀"法**|盐水思想拆分分子分母判断大小|
|**双线法**|增速大小比较，标注增量X直观比较|

### 6.2 替代比较技巧

> **[方法] 四种替代思路（提速关键）**
> 
> 1. 用**末期/基期**代替年均增长率比较（省去开方）
>     
> 2. 用**倍数B/A**代替增速(B/A-1)比较（省去减1）
>     
> 3. 用**部分A/部分非A**代替部分A/整体比较
>     
> 4. 用**X/B**代替X/A比较增长率
>     

### 6.3 增量大小比较

> **增量比较秒杀计**
> 
> ① B越大 R越大 → X越大（大大则大） ② 一大一小看倍数

**追及问题**：顺差=出口-进口，出口增量>进口增量→顺差增大。

### 6.4 特殊比较

- **超过某数值**：将增量拆成10%和剩余部分判断
    
- **折线图**：先确定增减方向，再比较相对大小

## 七、平均数与倍数

### 7.1 平均数

> **平均数 = 总数A / 个数B**
> 
> 识别："均""每""单位" → 均前每后做分母

题型全览：

1. 求单个平均数
    
2. 两个平均数之比：`A/B ÷ C/D = AD/BC`
    
3. 基期平均数（同基期比重公式）
    
4. 平均数变化趋势（同比重趋势）
    
5. 平均数差值（同比值差公式）
    
6. 平均数增长率（同比值增长率）
    

> **[注意]** 时间平均数注意闰年366天、季度个数、大小月。

### 7.2 倍数

> **倍数公式组**
> 
> - A是B的多少倍：`A/B`
>     
> - A比B多多少倍：`A/B - 1`
>     
> - 基期倍数 = `现期倍数 × (1+R2)/(1+R1)`
>     
> - 翻n番：A是B的 `2^n` 倍
>     
> - 间隔倍数 = 间隔增长率 + 100%
>

## 八、特殊考点

### 8.1 拉动增长与增量贡献率

> **拉动增长与贡献率**
> 
> - `拉动增长 = 部分增量 / 整体前期（基期）`
>     
> - `增量贡献率 = 部分增量 / 整体增量`
>     

> **[方法]** 比较不同部分对同一整体的贡献率时，整体增量相同，只需比较部分增量大小。

### 8.2 容斥问题

> **[方法] 容斥四步法**
> 
> 1. 判断有无交集：占比之和超过100% → 一定有交集
>     
> 2. 求至少（最小交集）：`a + b - 100%`
>     
> 3. 求至多（最大交集）：取占比较少项的比重
>     
> 4. 既A又B的范围：在"至少"和"至多"之间
>

## 九、易错点与思维陷阱

### 9.1 比较/计数类陷阱

|序号|陷阱|说明|
|---|---|---|
|①|**时间范围**|问"2011~2020年"则2010年不要算|
|②|**合计/总计行**|"全国""合计"行不要当独立项计数|
|③|**首年增量**|首年增量需用增长率求，后面用X=B-A|
|④|**单位**|注意不同指标单位差异（万吨vs亿吨）|
|⑤|**排序方向**|确认从高到低还是从低到高|
|⑥|**图表列举不全**|图表可能只列出部分省市|
|⑦|**时间不匹配**|1~7月数据推不出全年|

### 9.2 审题陷阱

|序号|陷阱|说明|
|---|---|---|
|⑧|**同比/环比混淆**|同比=去年同期，环比=前一周期|
|⑨|**"是多少倍"vs"多多少倍"**|二者差1|
|⑩|**比重分母**|看清占谁的比重，隔级需转换|
|⑪|**进出口主客颠倒**|欧盟从我国进口=我国对欧盟出口|
|⑫|**累计与当期**|8月累计=1~8月总和，非8月当月|
|⑬|**月均遗漏**|问1~8月月均增量要÷8|
|⑭|**一二月合并**|无法单独确定1月或2月值|

### 9.3 做题策略

> **[积累] 实战建议**

> - 综合分析题先查找比较再计算，避免反复读题
>     
> - 选项差距大时用估算（415/拆分），极近时用精确计算或选项代入法
>     
> - 查找数据时注意整体和部分的位置关系，避免看错行
