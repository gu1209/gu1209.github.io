# 花生13（四海公考）判断推理模块学习笔记

---

## 一、图形推理

### 1.1 基本思路与考场策略

**考场思维**：图推容易陷入自己世界不自知，时间悄然流逝。建议实战中图推分两至三次完成：

- 第一轮：花3~4分钟把3~5道简单题搞定
    
- 第二轮：回头花2~3分钟看剩余图推
    
- 第三轮：涂卡时再看剩余题目，常有"灵光乍现"
    

**练习思维**：利用碎片化时间，花十分钟做十道题。没看出来的题拍照或印在脑中，白天空闲时想一想。

**图推整体思维（核心口诀）**：

> **题干找共性，选项找差异，整体判方向，细节猜心思。**

### 1.2 定性分析（屈臣氏整风）

"屈臣氏整风"是定性分析的速记口诀，涵盖六大考点：

|口诀|考点|细化内容|
|---|---|---|
|**屈**|曲直性|有无曲线；全曲/全直/曲直；曲线数量；曲线与直线关系（相切/相交/相离）|
|**臣**|对称性|对称性质（轴对称/中心对称/两者兼具）；对称轴方向；对称轴数量；过点过线过面；多条对称轴位置关系；整体对称|
|**氏**|相同相似|各图形间均存在同一元素；内部存在相同元素或内外元素相似；相邻图形有相同相似元素（元素前后传递）|
|**整**|整体部分|整体图形与多部分图形；各图形的部分数|
|**风**|封闭开放|是否存在封闭空间；全封闭/半封闭/全开放性质判断；封闭空间数量|
|**奇偶**|奇偶性|某种元素数量的奇数/偶数分类|

**对称性"三大哥三小弟"**：

- **三大哥**：性质（轴对称还是中心对称）、数量（几条对称轴）、方向（横、竖、45度等）
    
- **三小弟**：过点过线过面、位置关系、整体对称
    

**常见对称图形速记**：

- 中心对称：Z、S、N、风车、太极、平行四边形
    
- 既是轴对称又是中心对称：H、I、O
    

### 1.3 定量分析（点线面角素）

|考点|细化内容|
|---|---|
|**点**|曲直交点；十字交点；切点；内部交点；外框交点；拐点处特征|
|**线**|直线数；曲线数；横竖线数量；笔画数；内外数量和差；点发射射线数|
|**面**|封闭空间数；相同面数量；面的面积|
|**角**|直角数量；锐角/钝角数量|
|**素**|元素种类；元素个数；元素换算；元素遍历|

**笔画数核心知识**：

- **奇点**：发射出奇数条射线的点（包括端点/露头、T点）
    
- **公式**：奇点数 / 2 = 笔画数
    
- **一笔画判定**：0个奇点或2个奇点
    
- **"吹捏法"**：形成封闭空间就可以去掉（捏掉独立单区域空间），剩下线条几笔画，原图即为几笔画
    
- **提示特征**：出头、T点、分离、特殊符号（日、田、☆、奥迪车标等）
    

**元素换算解题思路**：

- 两种元素数量逐渐增多时，考虑等差递增
    
- 可代入计算：如 2A + 6B = 4A + 2B，则 A = 2B
    

### 1.4 位置分析（直接想位移）

图形样式相同或相似但位置变化时考虑。

|口诀|考点|细化内容|
|---|---|---|
|**直**|垂直平行|垂直平行关系；平行线组数|
|**接**|连接方式|点连接/线连接；连接处特征；连接处线段数|
|**想**|方向|对称轴方向；折线首尾线段方向（平行/垂直、同向/反向）；特征线方向|
|**位**|位置关系|指示点位置；相对位置|
|**移**|移动|上下/左右/圆周移动；内外圈双移动；旋转/翻转；去同存异/去异存同；黑白块运算|

**移动题难点提示**：

- 折返移动（撞墙即返）
    
- 内外圈同时移动
    
- 六边形斜线移动
    
- 移动步数可能递增
    

### 1.5 四大类题型

#### 1.5.1 对称图类

考察维度：性质 -> 数量 -> 方向 -> 过点过线过面 -> 位置关系 -> 整体对称

#### 1.5.2 背景图类

**"三大哥"**：

- **移动**：轮廓相同 + 元素数量一致 + 远小于轮廓格子数 -> 优先移动
    
- **叠加**：轮廓相同 + 元素数量不一致（参差不齐） + "3x3"或"3+3"排列 -> 优先叠加（去异存同/去同存异）
    
- **部分数**：黑点呈顶格状，有切断感 -> 考虑部分数（黑白点抱团）
    

**"六小弟"**：

- **笔**：黑/白点连成线条状 -> 笔画数
    
- **面**：清晰图形轮廓 -> 面积/周长
    
- **连**：阴影位置存在点连接或线连接
    
- **报**（抱团）：图形杂乱分散，小黑块几个几个聚在一起
    
- **对**（对称）：黑格或白格分布规则
    
- **滴**（递推）：每行（列）均有阴影 + 相邻图形相似 + 行列很多（5x5以上）
    

#### 1.5.3 分割图类（口诀：连打三遍对象）

|考点|说明|
|---|---|
|连接方式|与外部轮廓公共边数量|
|大小|最大面和最小面相似|
|三不沾|中间图形与外部轮廓无公共点和公共边|
|边数|最大面/最小面/外部轮廓为规整多边形|
|对称|最大面/最小面为对称图形|
|相似|内部存在相同相似图形或内外相似|

#### 1.5.4 汉字类

|考点|说明|
|---|---|
|文字结构|左右/上下/全包围/半包围结构|
|笔画数/第一笔|笔画递增；每行第一笔相同|
|偏旁部首|每组均有相同部分|
|拼音|韵母规律；声母规律|
|空间数量/部分数|封闭空间数递增；部分数递增|
|曲直性|纯直/有曲线字母|

### 1.6 六提示（快速识别考点方向）

|提示|触发特征|常见考法|
|---|---|---|
|**平行组数**|两个相同/相似三角形；N/Z/工/H字型|平行线组数|
|**圆提示**|各图均有圆或曲线|圆内交点数；圆内空间数；直线与圆的相交/相切/相离；包围/半包围|
|**笔画数**|出头、T点、分离、日/田/☆|一笔画/多笔画|
|**连接方式**|简笔画（树叶、蜡烛等）|点连接/线连接|
|**直角数**|垂线、直角三角形、矩形|直角数递增/递减|
|**数量加减**|规整外部轮廓（多边形）；两种元素；"十"字|外部线条数与内部点/线/面之和差|

### 1.7 立体图形

#### 六面体展开图"三板斧"

1. **对立面排除**：应为对立面的两个面若相邻，直接排除
    
2. **平移法**：处理母图时，可将面1平移至面4右侧（反之亦可），面5、6随面1、4一起平移
    
3. **中心对称处理**：若面5、6为中心对称图形，可直接平移两格；否则需旋转180度
    

**对立面规律**：

- 点连接面：可绕公共点旋转
    
- 线连接面：保持公共边不变
    
- 对立面：永远不存在连接关系
    

#### 截面图

|立体|可截出图形|
|---|---|
|长方体|锐角三角形、梯形、平行四边形、非正五边形、六边形|
|圆柱|正圆形、椭圆形、长方形（正方形取决于高与直径之比）|
|圆锥|圆形、等腰三角形、椭圆形|

**解题原则**：一般可截出简单规整图形，"缺失"部分一般也是规整图形。不规整的选项可直接排除。

#### 立体视图

- 视图由**轮廓 + 内部线条**组成
    
- 内部线条来自不平滑的"棱"产生的实线
    
- 六个方向：主/后/左/右/俯/仰视图
    

#### 立体拼合

- 方法一：逐层画图法
    
- 方法二：将已知部分拼合后找缺失部分

## 二、定义判断

### 2.1 总体做题思想

> **定义判断更重理解，要站在一定高度上把握，可联系生活中的人或事或某种现象，试着猜测其现实所指。**

**核心原则**：

- 定义判断不是"连连看"，不能只找关键要素一一对应（"只见树木不见森林"）
    
- **被定义词**才是最关键信息——为什么选这个词作为定义名称，因为"名"里有最重要特征
    
- 读题过程 = 寻找被定义词中特征对应的过程
    

**需特别关注**：

- **主体**（谁在做）
    
- **对象**（对谁做）
    
- **特殊要求**（限定条件）
    
- **中心语**（核心是什么）
    

**最大陷阱**：

> 属于/不属于一定分清！养成良好读题习惯。不属于题目的错误选项都是"例子"，可借用例子理解定义。

### 2.2 单定义解题方法

#### 偏正短语式

被定义词为偏正短语时，重点拆解修饰语和中心语：

- 例：**体验式采访** = 体验式（修饰）+ 采访（中心语）-> 必须同时满足"体验"和"采访"
    
- 例：**无感审批** = 无感（修饰）+ 审批（中心语）-> 必须同时满足"自动/无感"和"审批"
    

#### 关键词提取法

|关注点|说明|举例|
|---|---|---|
|**主体**|谁在执行|企业、政府、档案馆、个人|
|**对象**|作用于谁|档案、犯罪嫌疑、患者|
|**时间限定**|何时发生|"起诉前"、"事前"|
|**方式/手段**|如何做|"智能技术"、"现代科学技术"|
|**目的/结果**|达到什么|"获得商业回报"、"预防中风"|
|**中心语**|本质是什么|燃料、系统、行为、投资|

### 2.3 多定义题处理

- 注意找**一一对应**关系
    
- 正确选项有时会**完美对应**定义结构
    
- 先明确每个定义的核心区别点，再逐一匹配
    

### 2.4 常用技巧

#### 造句法

将选项代入定义语句，判断是否成立。适用于抽象定义或关系类定义。

#### "与众不同"法

当多个选项看似都符合时，找到那个特殊的选项：

- 比较项中只有一个是"必须"的，其他都是"可有可无"的
    
- 选项中有"新旧方法"之分的
    

#### "新旧"判断法

当定义涉及新概念时：

- 看选项是传统方式还是创新方式
    
- 传统方式（几十年前就有的）不符合"新"概念
    

### 2.5 专业性定义

|领域|注意事项|
|---|---|
|**法律**|忠于罪名定义；注意"事前通谋"vs"事后帮助"；多做一步可能是其他罪名|
|**医学**|注意是长期过程还是短期现象；有根据vs无根据的惊慌|
|**经济/科学**|注意因果关系；解释变量vs被解释变量；时间滞后效应|

### 2.6 常见陷阱总结

|陷阱类型|说明|
|---|---|
|主体不符|选项中的执行者不是定义要求的主体|
|对象错误|作用对象与定义不一致|
|缺少核心要素|只满足部分条件，缺少关键要素|
|属于/不分清|题目问"不属于"却选了"属于"的|
|比较项干扰|选项在做无关比较而非直接否定|
|中心语偏离|选项本质不是定义所说的那类事物|

## 三、类比推理

### 3.1 总体做题思想

> **以我为主，主动找题干与选项的内在联系；切忌被出题人"牵着鼻子走"。**

- 类比推理是**假设性推理**，如果逼着自己给选项找理由，总能找到千奇百怪的理由
    
- 注意**"大众思维"**和**"简单思维"**，多想词与词本身的内在联系
    
- 常用方法：**造句子**（选择与题干相似点最多的选项）
    
- 也可设想更合适的答案是什么，以此排除错误选项
    

**关系层级**：

- **一级辨析**（优先看）：语义关系、范畴关系、对应关系
    
- **二级辨析**（再看）：语法关系、褒贬色彩、物理/化学变化
    

### 3.2 语义关系

|类型|说明|示例|
|---|---|---|
|**近义/反义**|词语含义相近或相反|先礼：后兵（反+反）|
|**引申/象征/双关**|词的引申义、象征义或一语双关|布衣：百姓（象征）；白鸽：和平（象征）|
|**意思解释**|一个词是对另一词的解释|转念：主意（转念=改变主意）|
|**同字不同义**|相同字在不同词中含义不同|峰：山峰（本义）：碳达峰（象征义）|

**成语常见考法**：语义 + 褒贬色彩 + 结构分析

- 近义成语需注意褒贬色彩差异（如"志同道合"褒义 vs "沆瀣一气"贬义）
    
- 满和盈不是同义，是递进关系（满了之后继续加才会盈）
    

### 3.3 语法关系

|类型|说明|示例|
|---|---|---|
|**词性考察**|名词/动词/形容词|手足（名+名，有本义和引申义）|
|**结构考察**|动宾/主谓/偏正/并列等|精准：扶贫（偏正）；蛛丝马迹（四个偏正）|
|**句子成分**|词语在句中的位置/成分|风险：社会：预防 -> 预防社会风险|

**结构分析要点**：

- 政通人和 = 政通 + 人和（并列）；国泰民安 = 国泰 + 民安（并列）
    
- 愚公移山、郑人买履 = 主谓宾结构
    
- 列锦手法：景色名词依次排列（枯藤老树昏鸦）
    

### 3.4 范畴关系

#### 全同关系

两个概念外延完全重合。包括：古今、中外、自他、雅俗、同义词等。

- 例：父亲 = 爸爸；蹴鞠 = 足球；引擎 = 发动机
    

#### 并列关系

|子类型|说明|判断方法|
|---|---|---|
|**矛盾关系**|非此即彼（除了A就是B）|两者之和 = 全部|
|**反对关系**|除A、B外还有其他|两者之和 < 全部|

**常见矛盾对**：

- 生/死、合法/非法、存在/虚无、物质/意识
    
- 硬件/软件、城市/农村、有偿服务/无偿服务
    
- 黑色金属/有色金属（除了黑色金属都属于有色金属）
    

#### 包含关系

|子类型|判断方法|示例|
|---|---|---|
|**种属关系**|"A是B的一种"|苏格拉底是人类（特指）|
|**组成关系**|"A是B的一部分"|石家庄是河北的一部分|

**易错点**：

- 特指 vs 泛指：苏格拉底（特指）vs 松树（泛指）
    
- 鳄鱼不是鱼（爬行动物）；蜗牛不是昆虫（软体动物）；蝙蝠、鲸鱼、海豚是哺乳动物
    
- 电气不是气；银河不是河；榆钱不是钱
    

#### 交叉关系

满足"有的A是B，有的A不是B，有的B不是A"。

- 常见交叉维度：**材质 + 功能**（铜镜：化妆镜；木碗：汤碗）
    
- 报案人：嫌疑人（同一案件中可为同一人）
    

### 3.5 对应关系

#### 逻辑性对应

|类型|说明|示例|
|---|---|---|
|**充分必要**|前推后/后推前|调查：发言权（没调查就没发言权，后推前）|
|**因果**|前因后果|春暖：花开；绳锯：木断|
|**行为目的**|前者为达到后者的行为|刻舟：求剑；投资：收益|
|**哲学关系**|相互作用|实践：认识（实践决定认识，认识指导实践）|
|**逆否命题**|A->B 等价于 非B->非A|开车不喝酒：喝酒不开车|

#### 日常性对应

|类型|说明|注意事项|
|---|---|---|
|**原材料**|A是B的原料|区分物理变化vs化学变化|
|**功能**|A具有B功能|注意功能的准确描述|
|**职业**|职业：工作内容：成果|注意工作内容的准确性|
|**前后顺序**|事件发生的先后|注意主体一致性和连续性|
|**场所**|地点：活动：对象|注意区分休息场所和活动场所|
|**命名方式**|以何命名|材质/图案/功能/属性命名|
|**属性**|事物具有的属性|区分属性vs功能|

#### 理论性对应

- **自然科学**：物理/化学/生物常识（导体、金属分类等）
    
- **文学常识**：作品-人物-外号对应；敬词/谦词区分
    
- **历史知识**：典故出处（如"讷言敏行"出自《论语》）

## 四、逻辑判断

### 4.1 归因论证

#### 整体框架

归因论证 = **对比实验/既成事实 + 原因分析**

|类型|说明|
|---|---|
|**对比实验归因**|通过实验分组对比得出结论（重点+难点）|
|**时间对比归因**|当前与以往对比找变化原因|
|**一般归因**|对既成事实进行原因分析|
|**直接根本原因**|原观点vs反对者观点的博弈|

#### 对比实验归因——三大质疑方式

|质疑方式|核心思路|力度|
|---|---|---|
|**另有他因**|找到实验组与对照组的另一不同点|中等|
|**因果倒置**|结果发生在原因之前，不能是此原因导致结果|较强|
|**否定此因**|直接否定题干认定的原因|较强|

**另有他因正确选项特征**：

> 回归实验，找到实验组和对照组的另一可能影响结果的不同点。

**常见错误选项**：

- 未谈论原因的选项
    
- 未分组的典型**伪他因**（"暴饮暴食也会长胖"没有回归实验）
    
- "有些"类选项
    
- 实验瑕疵类选项（样本不足等，质疑力度很弱）
    

**"继发关联"的另有他因**：

- A与B不存在因果关联，A和B均是共同原因C导致的结果
    
- 例：地球转速放缓与强震增多，均是地核变化的结果
    

**利用分组找到另有他因**：

- 根据最终结论确定实验组和对照组
    
- 在正确分组中找到另一可能影响结果的变量
    

#### 因果倒置

- 本质：**原因在结果之后**，不能是此原因导致了结果
    
- 因果倒置力度 > 另有他因
    

#### 否定此因

- 不探讨原因是什么，只是否定题干认定的原因
    
- 例："失智是脑部疾病导致的认知退化，跟睡眠时长无关"
    

#### 排除他因支持

- 排除其他可能影响结果的因素，让题干原因成为唯一可能
    
- 例："新型测速探头安装前后，实际违章案件数基本相同"（排除他因）
    

#### 时间对比归因

- 找到当前与过去的另一点不同来进行他因削弱
    
- **核心原则**：一直存在且无变化的事实不会是某种变化的原因，"变化"才是"变化"的原因
    

#### 直接根本原因（可秒杀题型）

- 题目结构：原观点 + 反对者观点
    
- 正确答案：原观点认为的原因是导致反对者认为的原因的根本原因
    
- 即：原观点 -> 反对者原因 -> 结果
    

### 4.2 一般质疑

#### 无论据有结论

- 题干结构：背景 + 分析 + 结论
    
- 质疑方式：提出反向论据
    
- 注意：话题一致，主体正确，贴合题干
    

#### 有论据有结论

|质疑方式|说明|适用场景|
|---|---|---|
|**质疑论据**|指出论据本身有问题|论据是个人观点/判断时|
|**增加反向论据**|找到题干未考虑的负面因素|题干只列优点/以偏概全时|
|**断点拆桥**|论据和结论不相关，"推不出"|论据与结论存在逻辑断层时|
|**质疑"无中生有"**|结论中出现过度推断的内容|结论过于绝对/夸大时|

**"虽然但是所以不"造句法**：

> 虽然（论据内容），但是（选项内容），所以结论是错误的

**断点拆桥核心**：找到论据和结论之间的逻辑跳跃点

- 例：论据是"第一场雪早"，结论是"冬天最冷"，断点是"下雪时间与气温无明显相关"
    

### 4.3 严谨逻辑关系质疑

若结论存在逻辑关联词（如果就/只有才/所有都），可翻译为 A->B，在选项中寻找 **A且非B**。

**命题真假判断**：

|前件A|后件B|A->B|
|---|---|---|
|真|真|真|
|真|假|**假**|
|假|真|真|
|假|假|真|

> **A->B为假，只有一种情况：A真且B假**

### 4.4 支持、前提假设与解释

#### 五种常见支持方式

1. **解释说明**：对结论进行原理解释
    
2. **断点搭桥**：弥补论据和结论之间的逻辑断裂
    
3. **增加正向论据**：补充有利的证据
    
4. **必要条件（反向代入）**：若该条件不成立，结论也不成立
    
5. **举例支持**：用具体例子证明结论
    

#### 三种常见前提假设

1. **断点搭桥**：连接论据和结论
    
2. **补充漏洞**：填补论证中的逻辑空缺
    
3. **必要条件/能与不能**：没有这个条件，结论无法成立
    

#### 变化/比较的支持

- **构成对比实验**：选项与题干形成"异因异果"的支持（四圈支持）
    
- **补充对比实验**："异因同果"/"同因异果"进行质疑（三圈质疑）
    

### 4.5 推出推理

#### 等价推出

- **与题干等价**：找到与题干逻辑等价的选项
    
- **与题干不等价**：找出不等价的选项
    

#### 正推与逆推

- **正推**：根据已知事实推导结论
    
- **逆推**：根据所需结果反推条件
    

#### 两难推理

- A->B 且 非A->B，则B一定成立
    

### 4.6 分析推理

#### 翻译规则速查表

|提示词|翻译|
|---|---|
|如果a那么b、若a则b、只要a就b|a -> b|
|只有a才b、必须a才b、不a不b|b -> a|
|除非a否则b、a否则b|非a -> b|
|b是a的基础/关键/前提|a -> b|
|a且b|a 且 b|
|a或b|a 或 b|
|非(a且b)|非a 或 非b|
|非(a或b)|非a 且 非b|

#### 真假话分析——矛盾法

**三类矛盾关系**：

1. A 和 非A；A且B 和 非A或非B；A或B 和 非A且非B
    
2. 所有 和 有些不；有些 和 所有不；可能 和 必然不
    
3. A->B 和 A且非B
    

**解题步骤**：

1. 找到矛盾的两个命题
    
2. 确定矛盾中必有一真一假
    
3. 根据题干真/假数量，判断其余命题的真假
    
4. 从确定为真/假的命题推导答案
    

#### 假设法

- 假设某条件为真，若推出矛盾则原假设为假
    
- 适用于：无法直接找到矛盾的情况
    

#### 代入法

- 从选项入手代入验证
    
- 适用于：选项信息充分或题干条件复杂时
    

### 4.7 范畴推理

#### 直言命题核心知识

|知识点|内容|
|---|---|
|**否定规则**|所有的否定 = 有些不；有些的否定 = 所有不|
|**推出关系**|所有 -> 有些 -> 特例（单向推出）|
|**有些特殊**|有些是推不出有些不是；有些A是B -> 有些B是A|

#### 集合关系——一分为二画图法

- 找到"所有A都（不）是B"，分为B和非B两部分
    
- 所有表述画实线，有些表述画虚线
    
- 在两侧分别标注各集合
    

**关键推导**：

- 两个"所有都"可以形成链条：所有A是B + 所有B是C -> 所有A是C
    
- 两侧分离的集合一定没有交集（一定为假）
    
- 虚线部分的位置不确定（可能为真也可能为假）

## 五、核心易错点速查

### 图形推理易错点

1. 笔画数的奇点包括**端点（露头）**和**T点**
    
2. "过线"要求对称轴和原图形的某条线**重合**，垂直不算
    
3. 背景图类"部分数"：黑点顶格时注意黑白点分别计算部分数
    
4. 截面图中圆锥只能截出**等腰三角形**，不能截出一般三角形
    
5. 六面体展开图中对立面永远不相邻
    

### 定义判断易错点

1. 一定要看清是"属于"还是"不属于"
    
2. 被定义词本身包含最重要的特征，不要忽略
    
3. 比较项选项往往不是正确答案
    
4. "有些"/"部分"类选项通常质疑力度不足
    
5. 专业性定义要忠于专业术语的准确含义
    

### 类比推理易错点

1. 种属关系注意特指vs泛指
    
2. 矛盾关系 vs 反对关系：矛盾是"非此即彼"，反对是"还有其他"
    
3. 原材料题注意区分物理变化vs化学变化
    
4. 造句法要选择与题干**相似点最多**的选项
    
5. 范畴关系是一级辨析，语法关系多为二级辨析
    

### 逻辑判断易错点

1. 另有他因必须**回归实验**，伪他因（未回归实验的泛泛而谈）不是正确选项
    
2. 因果倒置力度 > 另有他因
    
3. 实验瑕疵类选项（样本不足等）质疑力度很弱
    
4. A->B为假**只有**一种情况：A真且B假
    
5. "有些是"推不出"有些不是"；"有些不"推不出"所有都不"
    
6. 一直存在且无变化的事实不是变化的原因
